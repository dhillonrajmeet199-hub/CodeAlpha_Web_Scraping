# Web Scraping Project

## Project Overview
This project collects book information from Books to Scrape using Python web scraping techniques.

## Tools and Libraries
- Python
- Requests
- BeautifulSoup
- Pandas

## Data Collected
- Book titles
- Prices
- Availability
- Ratings

## Dataset
The scraped book information is saved in a CSV file for further analysis.

## Website
https://books.toscrape.com/

## Purpose
This project demonstrates basic web scraping, data extraction, and CSV data storage using Python.
